# Deskio Roadmap 🗺️

Our mission is to give every Windows user a calm, deliberate, and beautifully curated desktop—with zero risk, zero lock-in, and instant one-click restore.

---

## 📍 v1.0.0 — The Foundation *(Current)*

- [x] **Nine Signature Styles**: Hand-tuned icon styles (`Squircle`, `Blueprint`, `Pixel Era`, `Gleam`, `Glaze`, `Die-Cut`, `Porthole`, `Scrapbook`, `Creekstone`).
- [x] **Zero-Risk Restore**: Byte-for-byte desktop snapshot & one-click restore back to the original Windows defaults.
- [x] **Shortcut Arrow Cleaner**: Native shortcut arrow removal with complete toggle-back capability.
- [x] **Wallpaper Zones & Organizers**: Grid-snapped desktop organizer zones with frost and blur materials.
- [x] **Windows 11 Fluent Acrylic Design**: Native-feeling desktop shell with dark/light mode and modern iconography.
- [x] **100% Offline & Private**: Zero tracking, zero telemetry, local-only execution.

---

## 🚀 v1.1.0 — Extended Customization *(In Progress)*

- [ ] **Custom Style Tuning**: Allow users to tweak border radius, elevation shadows, and plate colors beyond built-in presets.
- [ ] **Preset Import / Export**: Share `.dmpreset` packages with friends and the community.
- [ ] **Color Wheel & Hex Picker**: Custom color matching for accent palettes.
- [ ] **Dynamic Windows Theme Sync**: Automatically transition desktop styles and wallpaper zones when Windows toggles between Dark and Light mode.

---

## 🎨 v1.2.0 — Smart Desktop Layouts *(Planned)*

- [ ] **Time-of-Day Transitions**: Adaptive wallpaper dimming and zone lighting (morning, workday, evening).
- [ ] **Smart File Grouping**: Auto-categorize desktop files into designated zones based on extension or modification date.
- [ ] **Portable Release**: Standalone zero-install `.zip` package for users without administrative setup privileges.
- [ ] **Additional Community Styles**: 3 new icon aesthetics crafted based on user feedback.

---

## 🔭 Future Horizons

- [ ] **Community Style Gallery**: Browse and download community-created desktop makeover packs directly within the app.
- [ ] **Plugin System**: Lightweight local plugins for specialized desktop widgets (system monitor, daily task glance).
